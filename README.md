WEB_PROJECT_AROUND_ES

Aplicación web interactiva para gestionar un perfil y una colección de lugares.

## Funcionalidad

- Muestra una galería de tarjetas iniciales.
- Permite añadir tarjetas, indicar "Me gusta" y eliminarlas.
- Permite editar el nombre, la ocupación y la imagen del perfil.
- Abre una vista ampliada al seleccionar una imagen.
- Valida los formularios y muestra sus errores en pantalla.
- Cierra las ventanas emergentes con su botón, al hacer clic fuera de ellas o con la tecla Escape.

## Tecnologías

- HTML5 y CSS3 con metodología BEM.
- TypeScript con clases, interfaces y módulos ES.
- JavaScript compilado en la carpeta `public` mediante TypeScript.

## Desarrollo

El código fuente está en `src` y los archivos compilados se generan en `public`.

```bash
tsc
```
